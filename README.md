## 02 — Aim-MVITG

**Instruction-Guided Multimodal Video Understanding and Temporal Frame Selection**

**Focus:** Video Understanding · Multimodal AI · Vision-Language Models · Temporal Reasoning

A research-oriented framework investigating whether **instruction-guided temporal frame selection** can provide more relevant visual information to video-language models than conventional uniform frame sampling.

The project evaluates instruction-guided frame selection against uniform sampling across multiple video understanding benchmarks and VLM configurations.

Research themes include:

* Temporal frame selection
* Instruction-guided visual reasoning
* Long-video understanding
* Vision-language models
* Temporal relevance modeling
* Multimodal video reasoning

This project directly reflects my interest in **video understanding and temporal multimodal intelligence**.

## 03 — AstronomicalSupernova-SciML

**Multimodal Scientific Machine Learning for Astronomical Transient Classification**

**Focus:** Scientific ML · Multimodal Learning · Representation Learning · Astronomy

A multimodal scientific machine learning framework for astronomical transient analysis using complementary observational modalities, including:

* Light curves
* Spectra
* Host-galaxy images
* Astronomical metadata

The research explores multimodal representation learning, contrastive learning, masked light-curve pretraining, redshift regression, transient classification, modality ablation, embedding analysis, and retrieval diagnostics.

This project extends my machine learning research into **scientific data analysis and multimodal learning**, particularly where different observational modalities describe the same underlying physical phenomenon.

## 04 — Self-Supervised-Learning

**Self-Supervised Visual Representation Learning with SwAV and Auxiliary Rotation Prediction**

**Focus:** Representation Learning · Self-Supervised Learning · Computer Vision

An experimental framework investigating visual representation learning through **SwAV-based self-supervised learning** combined with an auxiliary rotation-prediction objective.

The implementation explores:

* Multi-crop augmentation
* Prototype-based representation learning
* Sinkhorn-Knopp assignment
* Projection heads
* LARS optimization
* Warmup and cosine scheduling
* Mixed-precision training
* Distributed training
* Linear evaluation

The central research direction is understanding how **self-supervised objectives influence the quality and structure of learned visual representations**.

# Research Output

### Why Kinetics-Pretrained 3D CNNs Fail on Overhead CCTV Footage

**An Empirical Study of Domain Gap, Data Constraints, and Input Preprocessing in Retail Theft Detection**

This research investigates why a Kinetics-pretrained 3D CNN that performs effectively on conventional/frontal video data can experience substantial degradation when applied to real-world overhead CCTV footage.

The study examines factors including:

* Camera viewpoint and domain shift
* Temporal sampling
* Input preprocessing
* Data augmentation
* Person cropping
* Fine-tuning depth
* Dataset constraints
* Deployment-time sampling consistency

The broader research question is how **video representation learning models transfer across substantially different visual environments**, particularly when the target domain contains overhead viewpoints, foreshortening, fisheye distortion, subtle actions, and surveillance-specific temporal characteristics.
